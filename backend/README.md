# yalla-5roga-backend

Install with `pnpm install --frozen-lockfile` on Node.js 24. Use `pnpm dev:device` for shared-service local development (automatic mutation/cleanup jobs disabled), `pnpm build` for the compiled API and `pnpm start:production` for hosted startup. Both runtime commands load the selected root profile. Operations and tests follow the [environment reference](../docs/development/ENVIRONMENT_CONFIGURATION.md) and [deployment runbook](../docs/development/PRODUCTION_DEPLOYMENT.md).
